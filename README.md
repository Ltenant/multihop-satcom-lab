# Многоскачковая спутниковая линия связи (MATLAB)

Моделирование многоскачковой линии спутниковой связи между двумя наземными
станциями с регенеративными ретрансляторами.

## Состав

| Файл | Назначение |
|---|---|
| `multihop_satcom.m` | Основной скрипт: сценарий, спутники, карданные подвесы (gimbal), приёмопередатчики с гауссовскими антеннами, анализ линии `link`, таблица интервалов замыкания `linkIntervals`, график энергетического резерва `ebno` |
| `scenario_geometry.m` | 3D-визуализация геометрии сценария (орбиты + межспутниковая линия) без Satellite Scenario Viewer |

## Требования

- MATLAB **R2025b** или новее (функции `gimbal`, `gaussianAntenna`, `link` появились в Satellite Communications Toolbox)
- [Satellite Communications Toolbox](https://mathworks.com/products/satellite-communications.html)

## Запуск

```matlab
multihop_satcom        % основной расчёт: интервалы связи и запас линии
scenario_geometry      % 3D-снимок геометрии сценария
```

## Схема линии

```
GS1 (uplink 30 ГГц) -> Sat1 -> (crosslink 30 ГГц) -> Sat2 -> (downlink 27 ГГц) -> GS2
```

Каждый спутник работает как регенеративный ретранслятор: принимает,
демодулирует, ремодулирует, усиливает и ретранслирует сигнал.
